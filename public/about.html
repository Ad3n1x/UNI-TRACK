UNI-TRACK by AD3N1X

What is UNI-TRACK by AD3N1X?

UNI-TRACK by AD3N1X is an independent personal tracking and productivity web application. It helps people organise habits, tasks, goals and personal metrics with configurable trackers and progress records.

What does UNI-TRACK help people do?

Users can create trackers for habits, counters, logs, tasks, goals and other personal metrics. Tracker lists, filters and dashboard views help organise recorded progress. Supported tracking data can be exported as CSV, and browser push notifications are available where the browser, device and permissions allow them.

Who created UNI-TRACK?

UNI-TRACK is created by Adeniran Victor Adebowale, who publishes software under the developer identity AD3N1X. It is an independent project maintained in the official UNI-TRACK source repository.

Is UNI-TRACK the same as other products with similar names?

No. This page describes the AD3N1X project at unitrack-app.vercel.app. Other applications and services may use names such as UniTrack or UniTrack AI; they are not this project unless their publisher and official links match.

What should users know about privacy?

The application includes client-side encryption and decryption utilities for supported tracking data. This does not establish that every account field, API request or stored record is end-to-end encrypted. Do not assume universal end-to-end encryption or absolute privacy. Review the current application disclosures and implementation before relying on a particular security guarantee.
